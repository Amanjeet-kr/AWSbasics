Team 01 — Hands-on Tasks
Task 1 — Fix the C Program

Open the C program located in the c/ folder.

Find and fix the error(s) in the program.

Make sure the program compiles successfully.

Run the program and verify that it produces the expected output.

Task 2 — Linux File Management

Using Linux commands, modify the folder structure.

Create one or two new folders inside the team folder.

Create one or more text files inside the new folder(s).

Add some meaningful textual data related to your team/event in the files.

Make sure the new files and folders are present in your final submission.

Task 3 — Fix the Web Page

Open the files inside the web/ folder.

Find and fix the error(s) in the HTML/CSS code.

Make sure the webpage displays correctly in a browser.

Make at least one small improvement to the webpage, such as changing text, colors, layout, or styling.

Task 4 — Optional: Create Your Own GitHub Repository

Create a new public GitHub repository using your team name.

Upload your completed team folder to the repository.

Make sure all your changes and newly created files are included.

Submit the link to your GitHub repository.

Task 5 — Final Submission

Submit your completed team folder through the Google Form provided by the organizers.

Before submitting, make sure that:

All required tasks are completed.

Your modified files are present.

Your newly created folders and text files are included.

The folder opens correctly and contains your team's work.
