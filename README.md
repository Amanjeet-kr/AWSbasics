# AWS SBG: Linux & GitHub Starter Challenge

Welcome to our AWS SBG inauguration hands-on activity!

Your mission is to repair a small project, organize its files using Linux
commands, and submit your changes through GitHub.

No AWS account or paid cloud resources are required.

## What you will learn

- Navigating folders with `pwd`, `ls`, and `cd`
- Reading files with `cat`
- Creating folders and files with `mkdir` and `touch`
- Copying, renaming, and deleting files with `cp`, `mv`, and `rm`
- Editing files in a terminal editor
- Finding and fixing simple programming bugs
- Using Git branches, commits, and pushes
- Opening a GitHub pull request

## Challenge format

Each team has an assigned folder:

- `team-01/`
- `team-02/`
- And so on, depending on the number of teams

Only modify your assigned team's folder.

Each team project contains:

| Folder | Purpose |
|--------|---------|
| `web/` | A small HTML, CSS, and JavaScript website |
| `c/` | A beginner C program |
| `java/` | A beginner Java program |
| `notes/` | Files for Linux file-management exercises |
| `cleanup/` | An obsolete file to remove |

## Before you begin

1. Read [SETUP.md](SETUP.md).
2. Fork this repository and clone your fork.
3. Create a branch for your team.
4. Open `TASKS.md` inside your assigned folder.

For a beginner-friendly workflow, cloning the full repository is fine.
You do not need to download only your team folder.

## Team roles

Suggested roles:

- Terminal operator
- Code reader/debugger
- Tester
- Git and documentation coordinator

Rotate roles so everyone gets hands-on practice.

## Rules

1. Work only inside your assigned team folder.
2. Use Linux commands for file-management tasks.
3. Use a terminal editor such as `nano` if available.
4. Do not upload passwords, access keys, or personal information.
5. Do not commit compiled executables or Java `.class` files.
6. Ask a mentor before running a command you do not understand.
7. Never use `sudo rm` or broad deletion commands during this activity.

## Suggested duration

- Setup: 10 minutes
- Linux tasks: 15 minutes
- Web debugging: 20 minutes
- C and Java bonus tasks: 10 minutes
